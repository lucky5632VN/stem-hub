# T07 — Kiểm thử tổng hợp, điền báo cáo số thật, đóng gói & rà soát bí mật

- **R liên quan**: R4
- **Phụ thuộc**: T01..T06
- **Ưu tiên**: Must | **Thời gian**: 25 phút (Nhanh: 20' / Chậm: 35')
- **Tệp dự kiến**: `reports/unit_test_summary.json`, `reports/security_package_summary.json`, `docs/ke-hoach-6h/BAO_CAO_HOAN_CHINH.md`

## Các bước thực hiện
1. Chạy `npm run test:unit` + `node tests/safety_control.test.mjs`, xuất tóm tắt ra `reports/unit_test_summary.json`.
2. Chạy `npm run build` kiểm tra build Next.js production sạch lỗi.
3. Chạy `node scripts/package_submission.mjs` và `gitleaks dir --redact scratch/test_unpacked`, xuất kết quả ra `reports/security_package_summary.json`.
4. Chạy `node scripts/render_report_numbers.mjs` để điền toàn bộ số liệu thật vào `docs/ke-hoach-6h/BAO_CAO_HOAN_CHINH.md`.
5. *(Chỉ khi có lệnh của người quyết định)*: Triển khai production (Rules + Frontend cùng đợt) và smoke test ẩn danh.

## Kiểm thử & Nghiệm thu
- Lệnh kiểm thử: `npm run test:unit && node tests/safety_control.test.mjs && npm run build && node scripts/render_report_numbers.mjs`
- Nghiệm thu: Mọi test pass, build exit 0, `gitleaks` 0 rò rỉ, `render_report_numbers.mjs` `[PASS]`.

## Rủi ro
- Quên chạy lại `eval_safety_cases.mjs` sau khi sửa lỗi cuối -> luôn chạy lại T06 trước bước `render_report_numbers.mjs`.
